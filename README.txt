Teacher Resource Centre deployment package

Contents:
- index.html: Updated homepage. The Lesson Planner Templates link downloads the Word document directly.
- downloads/planner_templete.docx: The lesson planner template Word document.

Deployment:
1. Extract this ZIP.
2. Upload index.html to public_html (back up the old homepage first).
3. Upload the downloads folder into public_html, preserving its structure.
4. Test the Lesson Planner Templates link. It should download planner_templete.docx directly.
